# Event_Call_Example

##  Project Overview

This project demonstrates how a **Click Event** works in JavaScript.

When the user clicks the button, the **click event** is triggered, a JavaScript function is called, and a message is printed on the webpage or in the browser console indicating that the event has occurred.


##  Features

* Simple HTML, CSS, and JavaScript
* Demonstrates the **Click Event**
* Calls a JavaScript function on button click
* Prints **"Event Call Hua"** (or **"Click Event Called"**) after clicking the button
* Beginner-friendly example

##   How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Click the **Button**.
5. You will see a message such as:


Button Click Hua



##  How It Works

1. The webpage contains a button.
2. A **click event listener** is attached to the button.
3. When the button is clicked:

   * The click event is triggered.
   * The JavaScript function executes.
   * A message is displayed or printed in the console.



##   Expected Output

Before Clicking:


[ Button ]


After Clicking:


Button Click Hua




##  Learning Outcome

This project helps beginners understand:

* What is an Event?
* What is a Click Event?
* How Event Handling works in JavaScript
* How to call a function using a button click
* How to display output after an event is triggered
